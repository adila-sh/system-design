## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/ascii-heatmap.json
```

## Uso

```tsx
import { AsciiHeatmap } from "@adila-sh/ui";

<AsciiHeatmap
  label="Atividade"
  values={[
    [0, 2, 5],
    [1, 4, 8],
  ]}
/>;
```
