## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
const cities = [
  { value: "sao-paulo", label: "São Paulo" },
  { value: "recife", label: "Recife" },
];

<Autocomplete
  options={cities}
  placeholder="Digite uma cidade..."
  onValueChange={(value) => searchCities(value)}
  loading={isLoading}
/>;
```

O valor pode permanecer como texto livre. Para restringir a escolha aos itens
da lista, use [Combobox](/docs/components/combobox).
