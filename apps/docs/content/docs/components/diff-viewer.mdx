## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/diff-viewer.json
```

## Uso

```tsx
import { DiffViewer } from "@adila-sh/ui";

<DiffViewer
  filename="app.ts"
  oldCode="const version = 1;"
  newCode="const version = 2;"
  layout="split"
/>;
```

O componente utiliza [`@pierre/diffs`](https://diffs.com/docs), com Shiki para
syntax highlighting. Use `layout="unified"` ou `layout="split"`.
