## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
import { PackageInstall } from "@adila-sh/ui";

<PackageInstall commands={{ bun: "bun add zod" }} />;
```

O componente pode ser controlado com `manager` e `onManagerChange`.
