## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
import { SearchInput } from "@adila-sh/ui";

<SearchInput
  placeholder="Buscar componentes..."
  debounce={400}
  onSearch={(term) => fetchResults(term)}
/>;
```

Defina `loading` durante a busca. O botão de limpar aparece automaticamente
quando o campo possui conteúdo.
