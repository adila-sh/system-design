import {

  LockKeyhole,
  RefreshCw,

  Wrench,

Use `PageState` para comunicar um estado que substitui o conteúdo principal da
página. Para listas e áreas menores sem conteúdo, prefira o componente
[Empty](/docs/components/empty).

variante, a mensagem e as ações conforme o que a pessoa pode fazer em seguida.

## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
import {
  PageState,
  PageStateActions,
  PageStateContent,
  PageStateDescription,
  PageStateTitle,
} from "@adila-sh/ui";
```

### Variantes

- `default`: página não encontrada ou estado informativo.
- `muted`: indisponibilidade neutra ou falta de conexão.
- `warning`: atualização ou manutenção programada.
- `destructive`: falha crítica ou acesso negado.

## Acessibilidade

Mantenha um único `PageStateTitle` (`h1`) por página. Explique o que aconteceu e
ofereça apenas ações que ajudem a pessoa a continuar. Informações decorativas em
`PageStateBackdrop` já são ignoradas por leitores de tela.

## Dependências

- `class-variance-authority`
