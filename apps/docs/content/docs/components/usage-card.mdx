## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/usage-card.json
```

## Uso

```tsx
<UsageCard
  label="Armazenamento"
  description="Ciclo atual"
  value={82}
  max={100}
  warningAt={70}
  criticalAt={90}
  formatValue={(value, max) => `${value} / ${max} GB`}
/>
```

A barra muda para atenção e crítico ao atingir `warningAt` e `criticalAt`.
