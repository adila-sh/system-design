## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
<CurrencyInput
  name="amount"
  value={amount}
  onValueChange={(value) => setAmount(value)}
  min={0}
  inputProps={{ "aria-label": "Valor da cobrança" }}
/>
```

O valor recebido em `onValueChange` é numérico e não contém a máscara. O padrão
é `BRL` com locale `pt-BR`.
