## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
import type { DataTableColumnDef } from "@adila-sh/ui";

const columns: DataTableColumnDef<Customer>[] = [
  { accessorKey: "id", header: "ID" },
  {
    accessorKey: "name",
    header: ({ column }) => (
      <DataTableColumnHeader column={column} title="Cliente" />
    ),
  },
];

<DataTable
  columns={columns}
  data={customers}
/>;
```

Use a prop `toolbar` para inserir filtros ou ações adicionais. Ela também aceita
uma função que recebe a instância da tabela. `loading` renderiza linhas de
skeleton e `empty` permite personalizar o estado vazio.

## Dependências

- `@tanstack/react-table`
- `@phosphor-icons/react`
