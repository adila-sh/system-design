## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/status.json
```

## Uso

```tsx
import { Status } from "@/components/ui/status";

<Status>Rascunho</Status>
<Status variant="info">Em análise</Status>
<Status variant="success">Ativo</Status>
<Status variant="warning">Atenção</Status>
<Status variant="destructive">Bloqueado</Status>
```

As variantes disponíveis são `neutral`, `info`, `success`, `warning` e
`destructive`. Use `size="sm"`, `size="default"` ou `size="lg"` para ajustar a
densidade.

## Dependências

- `class-variance-authority`
