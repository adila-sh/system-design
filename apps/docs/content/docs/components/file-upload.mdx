## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
import { FileUpload } from "@adila-sh/ui";

<FileUpload
  accept="image/png,image/jpeg,application/pdf"
  maxSize={5 * 1024 * 1024}
  multiple
  onFilesChange={(files) => console.log(files)}
/>;
```

Use `value` e `onFilesChange` para controlar a lista externamente. Arquivos
maiores que `maxSize` são rejeitados com uma mensagem de erro.
