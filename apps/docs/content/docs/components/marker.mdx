## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
import { Marker, MarkerIcon, MarkerContent } from '@adila-sh/ui';
import { CheckCircle2 } from 'lucide-react';

export function Example() {
  return (
    <Marker>
      <MarkerIcon>
        <CheckCircle2 />
      </MarkerIcon>
      <MarkerContent>Pedido confirmado</MarkerContent>
    </Marker>
  );
}
```

`Marker` aceita `variant`: `default`, `separator` (linhas laterais ao redor do conteúdo) e `border` (borda inferior). Use `render` para transformar o marcador em outro elemento.

## Dependências
- `class-variance-authority`
