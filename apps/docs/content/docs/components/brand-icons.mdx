---
title: Brand Icons
description: Marcas vetoriais oficiais usadas nas integrações da Adila.
---

Os ícones de marca preservam a geometria e as cores oficiais e evitam cópias de
SVG diferentes entre produtos.

```tsx
import { GitHubBrandIcon, GoogleBrandIcon } from "@adila-sh/ui";

<GoogleBrandIcon className="size-4" />;
<GitHubBrandIcon className="size-4" />;
```

`GoogleBrandIcon` mantém suas quatro cores. `GitHubBrandIcon` usa
`currentColor`, portanto acompanha a cor do botão ou texto em que for inserido.
