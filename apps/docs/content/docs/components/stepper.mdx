## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/stepper.json
```

## Uso

```tsx
<Stepper>
  <StepperItem status="complete">
    <StepperIndicator>
      <CheckIcon />
    </StepperIndicator>
    <StepperSeparator />
    <StepperContent>
      <StepperTitle>Conta</StepperTitle>
    </StepperContent>
  </StepperItem>
  <StepperItem status="current">
    <StepperIndicator>2</StepperIndicator>
    <StepperSeparator />
    <StepperContent>
      <StepperTitle>Empresa</StepperTitle>
    </StepperContent>
  </StepperItem>
  <StepperItem status="upcoming">
    <StepperIndicator>3</StepperIndicator>
    <StepperContent>
      <StepperTitle>Confirmação</StepperTitle>
    </StepperContent>
  </StepperItem>
</Stepper>
```

Marque a etapa ativa com `status="current"`; o componente aplica
`aria-current="step"` automaticamente.
