---
title: Password Input
description: Campo de senha com alternância de visibilidade e aviso de Caps Lock.
---

import { PasswordInput } from "@adila-sh/ui";
import { Field, FieldDescription, FieldLabel } from "@adila-sh/ui";

<Preview>
  <Field className="w-full max-w-sm">
    <FieldLabel htmlFor="password-example">Senha</FieldLabel>
    <PasswordInput id="password-example" placeholder="Digite sua senha" />
    <FieldDescription>Use pelo menos 12 caracteres.</FieldDescription>
  </Field>
</Preview>

## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
<Field>
  <FieldLabel htmlFor="password">Senha</FieldLabel>
  <PasswordInput
    id="password"
    name="password"
    autoComplete="current-password"
    required
  />
</Field>
```

Os textos acessíveis dos botões podem ser personalizados com `showLabel` e
`hideLabel`.
