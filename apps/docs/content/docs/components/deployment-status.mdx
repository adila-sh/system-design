## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
<DeploymentStatus status={deployment.status} />
```

Os estados suportados são `queued`, `building`, `ready`, `failed` e `canceled`.
O estado `building` inclui um spinner e todos os estados possuem `role="status"`.
