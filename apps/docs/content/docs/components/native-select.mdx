```bash
bun add @adila-sh/ui
```

## Uso

`<select>` nativo estilizado — aceita todos os atributos do elemento (`name`,
`defaultValue`, `disabled`, `required`) e a prop `size="sm" | "default"`.

```tsx
import {
  NativeSelect,
  NativeSelectOptGroup,
  NativeSelectOption,
} from '@adila-sh/ui';

export function Example() {
  return (
    <NativeSelect name="plano" defaultValue="pro">
      <NativeSelectOptGroup label="Planos">
        <NativeSelectOption value="free">Free</NativeSelectOption>
        <NativeSelectOption value="pro">Pro</NativeSelectOption>
      </NativeSelectOptGroup>
      <NativeSelectOption value="enterprise">Enterprise</NativeSelectOption>
    </NativeSelect>
  );
}
```
