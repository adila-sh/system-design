---
title: Theme Provider
description: Tema claro, escuro ou do sistema com os defaults da Adila.
---

`ThemeProvider` centraliza a integração do design system com `next-themes`.
Por padrão, aplica `light` ou `dark` como classe no elemento `<html>`, respeita
a preferência do sistema e desabilita transições durante a troca.

## Instalação

```bash
bun add @adila-sh/ui
```

## Provider

```tsx
import { ThemeProvider } from "@adila-sh/ui";

export function App({ children }: { children: React.ReactNode }) {
  return <ThemeProvider>{children}</ThemeProvider>;
}
```

## Hook

```tsx
import { Button, useTheme } from "@adila-sh/ui";

export function ThemeToggle() {
  const { resolvedTheme, setTheme } = useTheme();

  return (
    <Button
      variant="outline"
      onClick={() => setTheme(resolvedTheme === "dark" ? "light" : "dark")}
    >
      Alternar tema
    </Button>
  );
}
```

Todas as propriedades do `next-themes` continuam disponíveis no provider para
temas customizados, outra chave de persistência ou outro atributo no documento.

> `CodeThemeProvider` é independente: ele seleciona a paleta de blocos de
> código, terminais e diffs, não o tema visual da aplicação.
