## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/timeline.json
```

## Uso

```tsx
<Timeline>
  <TimelineItem>
    <TimelineIndicator status="complete">
      <CheckIcon />
    </TimelineIndicator>
    <TimelineConnector />
    <TimelineContent>
      <TimelineHeader>
        <TimelineTitle>Pagamento aprovado</TimelineTitle>
        <TimelineTime dateTime="2026-07-18T10:32:00-03:00">10:32</TimelineTime>
      </TimelineHeader>
      <TimelineDescription>Cobrança confirmada.</TimelineDescription>
    </TimelineContent>
  </TimelineItem>
</Timeline>
```

Adicione `TimelineConnector` a todos os itens, exceto ao último. Use o atributo
`dateTime` em `TimelineTime` para manter o horário legível por máquinas.
