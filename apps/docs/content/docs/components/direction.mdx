import { DirectionProvider } from '@adila-sh/ui';

`DirectionProvider` não tem visual próprio: é um provedor de contexto que informa aos
componentes a direção do texto (`ltr` ou `rtl`). Envolva a árvore da aplicação
com ele para habilitar layouts da direita para a esquerda. O exemplo abaixo demonstra
uma seção em `rtl`.

<Preview>
  <DirectionProvider direction="rtl">
    <div dir="rtl" className="w-full max-w-sm rounded-md border p-4 text-sm">
      <p className="font-medium">مرحبا بك</p>
      <p className="text-muted-foreground">Conteúdo alinhado da direita para a esquerda.</p>
    </div>
  </DirectionProvider>
</Preview>

## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
import { DirectionProvider } from '@adila-sh/ui';

export function Example() {
  return (
    <DirectionProvider direction="rtl">
      <div dir="rtl">{/* componentes herdam a direção rtl */}</div>
    </DirectionProvider>
  );
}
```
