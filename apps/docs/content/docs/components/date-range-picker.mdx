## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/date-range-picker.json
```

## Uso

```tsx
<DateRangePicker
  value={period}
  onValueChange={setPeriod}
  numberOfMonths={2}
  clearable
/>
```

O tipo `DateRange` também é exportado pelo componente para estados controlados.
Em telas estreitas, use `numberOfMonths={1}`.
