## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

Renderize o `<Toaster />` uma única vez na raiz da aplicação e dispare
notificações de qualquer lugar com a função `toast` importada de `sonner`.

```tsx
import { Toaster } from '@adila-sh/ui';
import { Button } from '@adila-sh/ui';
import { toast } from 'sonner';

export function Example() {
  return (
    <>
      <Toaster />
      <Button
        variant="outline"
        onClick={() =>
          toast('Evento criado', {
            description: 'Segunda, 3 de julho às 09:00',
          })
        }
      >
        Mostrar notificação
      </Button>
    </>
  );
}
```

## Dependências

- `lucide-react`
