## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

Renderize o `<Toaster />` uma única vez na raiz da aplicação e dispare
notificações de qualquer lugar com a função `toast` do próprio design system.

```tsx
import { Button, Toaster, toast } from '@adila-sh/ui';

export function Example() {
  return (
    <>
      <Toaster />
      <Button
        variant="outline"
        onClick={() =>
          toast('Evento criado', {
            description: 'Segunda, 3 de julho às 09:00',
          })
        }
      >
        Mostrar notificação
      </Button>
    </>
  );
}
```

`sonner` é uma dependência interna do pacote e não precisa ser instalado nem
importado diretamente pela aplicação.
