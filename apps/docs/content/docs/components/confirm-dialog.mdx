## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/confirm-dialog.json
```

## Uso

```tsx
<ConfirmDialog
  trigger={<Button variant="destructive">Excluir</Button>}
  title="Excluir este projeto?"
  description="Essa ação não poderá ser desfeita."
  confirmLabel="Excluir projeto"
  pendingLabel="Excluindo..."
  variant="destructive"
  onConfirm={() => deleteProject(project.id)}
/>
```

Enquanto a Promise retornada por `onConfirm` estiver pendente, o diálogo
bloqueia novas interações. Em caso de erro, ele permanece aberto e exibe uma
mensagem.
