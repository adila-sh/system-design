## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/code-theme.json
```

## Uso

```tsx
import { CodeThemeProvider, CodeThemeSelect } from "@adila-sh/ui";

export function DeveloperTools({ children }: { children: React.ReactNode }) {
  return (
    <CodeThemeProvider defaultTheme="tokyo-night">
      <CodeThemeSelect />
      {children}
    </CodeThemeProvider>
  );
}
```

## Temas disponíveis

Claros:

- `github-light`
- `min-light`
- `solarized-light`

Escuros:

- `tokyo-night`
- `github-dark`
- `dracula`

O tema selecionado é compartilhado por `CodeBlock`, `Terminal`,
`PackageInstall`, `ApiRequest` e `DiffViewer`. O Pierre recebe o tema Shiki
correspondente, enquanto os demais componentes usam a mesma paleta por tokens
CSS.
