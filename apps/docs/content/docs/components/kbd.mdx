## Instalação

```bash
bun add @adila-sh/ui
```

## Uso

```tsx
import { Kbd, KbdGroup } from '@adila-sh/ui';

export function Example() {
  return (
    <KbdGroup>
      <Kbd>Ctrl</Kbd>
      <Kbd>Shift</Kbd>
      <Kbd>P</Kbd>
    </KbdGroup>
  );
}
```

Use `Kbd` para uma única tecla e `KbdGroup` para agrupar um atalho com múltiplas teclas.
