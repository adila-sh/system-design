## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/form.json
```

## Uso

```tsx
<Form
  validationMode="onBlur"
  errors={serverErrors}
  onFormSubmit={(values) => createProject(values)}
>
  <Field>{/* label, controle e erros */}</Field>
  <FormActions>
    <Button type="submit">Salvar</Button>
  </FormActions>
</Form>
```

Passe erros retornados pela API em `errors`, usando o nome de cada campo como
chave. `FormMessage` serve para falhas globais que não pertencem a um único
controle.
