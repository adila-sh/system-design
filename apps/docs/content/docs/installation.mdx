---
title: Como consumir
description: Instalar o pacote adila.co em outro projeto.
icon: Download
---

No projeto **consumidor**, configure o GitHub Packages e instale a biblioteca:

```bash
echo "@adila-sh:registry=https://npm.pkg.github.com" >> .npmrc
echo "//npm.pkg.github.com/:_authToken=\${NODE_AUTH_TOKEN}" >> .npmrc
bun add @adila-sh/ui
```

O pacote inclui os componentes, estilos e tokens do tema adila.co. Para usar um
componente:

```tsx
import { Button } from "@adila-sh/ui";

<Button>Continuar</Button>
```
