O **adila.co UI** é o design system da adila.co publicado como pacote React no
GitHub Packages. Instale a biblioteca em qualquer projeto Bun e use o tema
adila.co (indigo, neutros estilo ChatGPT, Adila Std / Adila Code / Adila Pixel),
em light e dark.

## O que tem aqui

- **60+ componentes** acessíveis para React, com os tokens adila.co em OKLCH.
- Documentação com **preview ao vivo** — os mesmos arquivos que são publicados.

## Instalação rápida

```bash
bun add @adila-sh/ui
```
