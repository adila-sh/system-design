O **adila.co UI Registry** é o design system adila.co publicado como um **registry shadcn
HTTP**. Qualquer projeto consome os componentes com a CLI do shadcn, já com o
tema adila.co (verde adila.co, neutros estilo ChatGPT, Circular Std / JetBrains Mono), em light e
dark.

## O que tem aqui

- **60+ primitives** shadcn sobre **Base UI** (não Radix), cada um como item
  `registry:ui`.
- Um item de tema **`adila-theme`** (`registry:style`) com os tokens adila.co em OKLCH.
- Documentação com **preview ao vivo** — os mesmos arquivos que são publicados.

## Instalação rápida

```bash
# tema (tokens adila.co)
npx shadcn@latest add https://<host>/r/adila-theme.json

# componentes
npx shadcn@latest add https://<host>/r/button.json
```
