## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/number-field.json
```

## Uso

```tsx
<NumberField
  value={quantity}
  onValueChange={(value) => setQuantity(value)}
  min={1}
  max={10}
>
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput aria-label="Quantidade" />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>
```

Use `step`, `smallStep` e `largeStep` para controlar teclado e botões. O campo
deve receber um nome acessível por `FieldLabel` ou `aria-label`.
