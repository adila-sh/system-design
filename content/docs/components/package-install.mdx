## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/package-install.json
```

## Uso

```tsx
import { PackageInstall } from "@/components/ui/package-install";

<PackageInstall commands={{ npm: "npm install zod", bun: "bun add zod" }} />;
```

O componente pode ser controlado com `manager` e `onManagerChange`.
