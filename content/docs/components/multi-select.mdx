## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/multi-select.json
```

## Uso

```tsx
const options = [
  { value: "deploy", label: "Deploy" },
  { value: "billing", label: "Cobrança" },
];

<MultiSelect
  options={options}
  value={permissions}
  onValueChange={setPermissions}
  placeholder="Selecionar permissões..."
/>;
```

Cada opção pode receber `disabled`. Para um único valor, prefira
[Combobox](/docs/components/combobox).
