## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/typography.json
```

## Uso

```tsx
import {
  CodeText,
  Description,
  Label,
  Lead,
  PixelText,
  Text,
  Title,
} from "@/components/ui/typography";

export function ArticleHeader() {
  return (
    <header className="space-y-3">
      <Label>Novidades</Label>
      <Title level={1}>Uma nova experiência</Title>
      <Lead>Uma introdução em destaque para contextualizar a página.</Lead>
      <Text>O conteúdo principal começa aqui.</Text>
      <PixelText>Um destaque com a fonte Adila Pixel.</PixelText>
      <CodeText>const font = "Adila Code";</CodeText>
      <Description>Publicado em 18 de julho de 2026.</Description>
    </header>
  );
}
```

## Títulos

`Title` renderiza `h1` por padrão. Use `level` de `1` a `6` para manter a
hierarquia semântica e aplicar a escala visual correspondente.

```tsx
<Title level={1}>Título da página</Title>
<Title level={2}>Título da seção</Title>
<Title level={3}>Título do bloco</Title>
```

## Componentes

- `Title`: títulos semânticos de `h1` a `h6`.
- `Text`: parágrafo de conteúdo padrão.
- `PixelText`: texto de destaque com a fonte Adila Pixel.
- `CodeText`: texto monoespaçado com a fonte Adila Code.
- `Lead`: introdução em destaque.
- `Label`: rótulo visual curto; para campos de formulário, use o componente `Label` de formulário.
- `Description`: texto explicativo secundário.
- `Small`: observações compactas.
- `Muted`: metadados e informações de menor ênfase.
- `InlineCode`: termos técnicos e trechos curtos de código.
- `Blockquote`: citações em bloco.
- `List`: lista não ordenada com ritmo tipográfico consistente.
