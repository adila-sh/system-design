## Instalação

```bash
npx shadcn@latest add https://<host>/r/navigation-menu.json
```

## Uso

```tsx
import { NavigationMenu, NavigationMenuContent, NavigationMenuIndicator, NavigationMenuItem, NavigationMenuLink, NavigationMenuList, NavigationMenuPositioner, NavigationMenuTrigger } from '@/components/ui/navigation-menu';
```

## Dependências

- `@base-ui/react`
- `class-variance-authority`
- `lucide-react`
