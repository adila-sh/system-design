## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/kbd.json
```

## Uso

```tsx
import { Kbd, KbdGroup } from '@/components/ui/kbd';

export function Example() {
  return (
    <KbdGroup>
      <Kbd>Ctrl</Kbd>
      <Kbd>Shift</Kbd>
      <Kbd>P</Kbd>
    </KbdGroup>
  );
}
```

Use `Kbd` para uma única tecla e `KbdGroup` para agrupar um atalho com múltiplas teclas.
