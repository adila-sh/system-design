## Instalação

```bash
npx shadcn@latest add https://<host>/r/breadcrumb.json
```

## Uso

```tsx
import { Breadcrumb, BreadcrumbEllipsis, BreadcrumbItem, BreadcrumbLink, BreadcrumbList, BreadcrumbPage, BreadcrumbSeparator } from '@/components/ui/breadcrumb';
```

## Dependências

- `@base-ui/react`
- `lucide-react`
