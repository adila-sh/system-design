## Instalação

```bash
npx shadcn@latest add https://ds.adila.co/r/code-block.json
```

## Uso

```tsx
import { CodeBlock } from "@/components/ui/code-block";

export function Example() {
  return (
    <CodeBlock
      code={`const greeting = 'Olá, mundo!';`}
      language="typescript"
      filename="example.ts"
      showLineNumbers
      highlightLines={[1]}
    />
  );
}
```

## Linguagens

O highlighter reconhece JavaScript, TypeScript, JSX, TSX, JSON, Bash, Shell,
CSS, HTML, SVG, XML e MDX. Linguagens não reconhecidas recebem a formatação
base sem comprometer a legibilidade.

## Linhas em destaque

Passe números de linha em `highlightLines` para chamar atenção para mudanças
ou trechos importantes.
